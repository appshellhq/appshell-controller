# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/appshellhq/appshell-controller/security/advisories/new),
rather than in a public issue.

Include what you found, how to reproduce it, and the version or commit it affects. You'll get an
acknowledgement, and we'll keep you informed as it's fixed and disclosed.

## Supported versions

Until 1.0, fixes land on `main` and in the next release.
